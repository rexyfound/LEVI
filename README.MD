# LEVI

> Autonomous Desktop AI Operating System

LEVI is an AI agent capable of:

- Multi-provider routing (Gemini, Groq, Ollama)
- Browser automation
- Desktop automation
- Long-term memory
- File operations
- Terminal execution
- Intelligent tool selection
